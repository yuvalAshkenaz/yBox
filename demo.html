yBox v13.4.1JavaScript Lightbox & Popup Libraryספריית Lightbox ופופאפים ב-JavaScript

yBox is a free, lightweight JavaScript lightbox and modal popup library for images, galleries, YouTube and Vimeo videos, HTML5 video, iframes, AJAX content and hidden page elements.
It is written in vanilla JavaScript with no dependencies (no jQuery), supports RTL with built-in Hebrew and Arabic, and is MIT licensed for personal and commercial use. yBox היא ספריית lightbox ופופאפים חינמית וקלה ב-JavaScript, לתמונות, גלריות, סרטוני YouTube ו-Vimeo, וידאו HTML5, iframe, תוכן AJAX ואלמנטים מוסתרים בדף.
היא כתובה ב-JavaScript נקי בלי תלויות (בלי jQuery), תומכת ב-RTL עם עברית וערבית מובנות, ומופצת ברישיון MIT לשימוש אישי ומסחרי.

Why yBox? A free Fancybox alternativeלמה yBox? חלופה חינמית ל-Fancybox

yBox covers the common lightbox and popup needs, images, galleries, video, iframes, AJAX and inline content, for free and without jQuery.
Fancybox requires a paid license for every live website, and Lightbox2 requires jQuery. yBox מכסה את הצרכים הנפוצים של lightbox ופופאפים, תמונות, גלריות, וידאו, iframe, AJAX ותוכן מהדף, בחינם ובלי jQuery.
Fancybox דורשת רישיון בתשלום לכל אתר חי, ו-Lightbox2 דורשת jQuery.

Installation & Filesהתקנה וקבצים

Include the CSS and JS files in your project: הוסיפו את קבצי ה-CSS וה-JS בפרויקט: 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/yuvalAshkenaz/yBox/dist/css/ybox.min.css" />
<script type="text/javascript" src="https://cdn.jsdelivr.net/gh/yuvalAshkenaz/yBox/dist/js/ybox.min.js"></script>

yBox detects the language automatically from the page's <html lang> attribute.
To set the language manually, add the lang parameter to the script URL, e.g. ybox.min.js?lang=he.
Supported languages: he, ar (anything else falls back to English). yBox מזהה את השפה אוטומטית לפי התכונה <html lang> של העמוד.
כדי לקבוע את השפה ידנית, הוסיפו את הפרמטר lang לכתובת הסקריפט, למשל ybox.min.js?lang=he.
שפות נתמכות: he, ar (כל ערך אחר יציג אנגלית).

You can download the files from Github:

ניתן להוריד את הקבצים מ-Github:

https://github.com/yuvalAshkenaz/yBox

Helper Classesקלאסים עיקריים

ClassקלאסDescriptionתיאור
.ybox
Required on every trigger element.
Add it to any element with href or data-href to open the link in the lightbox.
נדרש על כל אלמנט טריגר.
הוסיפו אותו לכל אלמנט עם href או data-href כדי לפתוח את הקישור בלייטבוקס.
<a href="#popup" class="ybox">Open</a>
.ybox-iframe
Opens the href / data-href link inside an iframe.
Not needed for YouTube / Vimeo links, they are detected automatically.
Add data-ybox-sandbox to restrict what the iframe can do (see Security).
פותח את הקישור שב-href / data-href בתוך iframe.
לא נדרש לקישורי YouTube / Vimeo, הם מזוהים אוטומטית.
הוסיפו data-ybox-sandbox כדי להגביל את מה שה-iframe יכול לעשות (ראו אבטחה).
<a href="https://example.com" class="ybox ybox-iframe">Open site</a>
.ybox-video
Opens the href / data-href link in a native HTML5 video player.
Not needed when the link ends with a video extension (.mp4, .m4v, .webm, .ogv, .ogg, .mov), even with query parameters.
Use it only for video links without an extension.
פותח את הקישור שב-href / data-href בנגן וידאו HTML5.
לא נדרש כשהקישור מסתיים בסיומת וידאו (.mp4, .m4v, .webm, .ogv, .ogg, .mov), גם אם יש אחריה פרמטרים.
יש להשתמש בו רק לקישורי וידאו בלי סיומת.
<a href="https://example.com/stream/123" class="ybox ybox-video">Play</a>
.ybox-ajax
Fetches the content of the href / data-href link via AJAX and shows it in the popup.
Same-origin only by default. To load from another domain, add data-ybox-allow-cross-origin (the other server must also allow CORS).
The response is inserted as HTML, so load only content you trust.
טוען את התוכן של הקישור שב-href / data-href באמצעות AJAX ומציג אותו בפופאפ.
כברירת מחדל רק מאותו דומיין. כדי לטעון מדומיין אחר, הוסיפו data-ybox-allow-cross-origin (גם השרת השני צריך לאפשר CORS).
התשובה מוזרקת כ-HTML, לכן טענו רק תוכן שאתם סומכים עליו.
<a href="/ajax/content.html" class="ybox ybox-ajax">Load</a>
.ybox-share
Opens a built-in social sharing popup.
On phones and tablets it opens the device share menu instead, with all the installed apps (falls back to the popup if the browser does not support it).
By default it shares the current page URL.
Use href or data-href to share a different URL.
פותח פופאפ שיתוף ברשתות חברתיות.
בטלפונים ובטאבלטים נפתח במקומו תפריט השיתוף של המכשיר, עם כל האפליקציות המותקנות (אם הדפדפן לא תומך בזה, נפתח הפופאפ).
כברירת מחדל משתף את כתובת הדף הנוכחי.
השתמשו ב-href או data-href כדי לשתף כתובת אחרת.
<button type="button" class="ybox ybox-share">Share</button>

TargetמיקודExampleדוגמהDescriptionתיאור
IDID href="#my-popup"
data-href="#my-popup"
Opens the element with this ID.
If no such ID exists, yBox looks for the class .my-popup instead.
פותח את האלמנט עם ה-ID הזה.
אם אין ID כזה, yBox מחפש במקומו את הקלאס .my-popup.
Classקלאס href=".my-popup"

  2. If not found, it opens the element with the same index as the clicked element.

  2. אם לא נמצא, נפתח האלמנט עם אותו אינדקס של האלמנט שנלחץ.

Securityאבטחה

yBox protects against XSS and unsafe links out of the box: yBox מגן מפני XSS וקישורים מסוכנים כברירת מחדל:

  • Escaped attributes — data-ybox-alt, data-ybox-title, data-ybox-headline, data-ybox-details-title, classes and URLs are always inserted as text, never as HTML.קידוד תכונות — data-ybox-alt, data-ybox-title, data-ybox-headline, data-ybox-details-title, קלאסים וכתובות תמיד מוזרקים כטקסט, אף פעם לא כ-HTML.
  • Safe protocols only — href / data-href / url must be http, https, mailto, tel, a relative path, #id or .class. javascript:, vbscript:, data: etc. are blocked (a warning is shown in the console). data:image is allowed only for thumbnails and posters.רק פרוטוקולים בטוחים — href / data-href / url חייבים להיות http, https, mailto, tel, נתיב יחסי, #id או .class. javascript:, vbscript:, data: וכו' נחסמים (מוצגת אזהרה בקונסול). data:image מותר רק לתמונות ממוזערות ול-poster.
  • URL parameter — ?ybox-id is treated only as an element ID.פרמטר URL — ?ybox-id משמש רק כ-ID של אלמנט.
  • AJAX — same-origin only, unless data-ybox-allow-cross-origin is set. Error responses (404, 500) are not inserted.AJAX — רק מאותו דומיין, אלא אם הוגדר data-ybox-allow-cross-origin. תשובות שגיאה (404, 500) לא מוזרקות.
  • Share windows — opened without access to window.opener (prevents reverse tabnabbing). The print button does not use a javascript: link, so it works with a strict CSP.חלונות שיתוף — נפתחים בלי גישה ל-window.opener (מונע reverse tabnabbing). כפתור ההדפסה לא משתמש בקישור javascript:, ולכן עובד גם עם CSP קפדני.
  • Iframe sandbox (opt-in) — add data-ybox-sandbox to restrict external sites.Sandbox ל-iframe (לפי בחירה) — הוסיפו data-ybox-sandbox כדי להגביל אתרים חיצוניים.

Your responsibilityבאחריותכם

  • yBox({ code }) inserts raw HTML. Never pass unsanitized user input — sanitize it first (for example with DOMPurify).yBox({ code }) מזריק HTML גולמי. אסור להעביר קלט משתמש בלי סינון — סננו אותו קודם (למשל עם DOMPurify).
  • Elements opened by #id / .class and data-ybox-details selectors show existing page HTML as-is — make sure that content is safe.אלמנטים שנפתחים לפי #id / .class וסלקטורים של data-ybox-details מציגים את ה-HTML הקיים בדף כמו שהוא — ודאו שהתוכן הזה בטוח.
  • AJAX responses are inserted as HTML — load only content you trust.תשובות AJAX מוזרקות כ-HTML — טענו רק תוכן שאתם סומכים עליו.
  • Clickjacking protection for your own site (X-Frame-Options / CSP frame-ancestors) is set on the server, not in yBox.הגנה מפני clickjacking לאתר שלכם (X-Frame-Options / CSP frame-ancestors) מוגדרת בשרת, לא ב-yBox.

Styling Headlinesעיצוב כותרות

Headlines are plain text for security, so style them with CSS instead of HTML: הכותרות הן טקסט רגיל מטעמי אבטחה, לכן מעצבים אותן ב-CSS ולא ב-HTML:

  1. Custom class — add data-ybox-headline-class and style it in your CSS.קלאס מותאם — הוסיפו data-ybox-headline-class ועצבו אותו ב-CSS.
  2. Default classes — .ybox-img-title (images & galleries), #ybox-iframe-headline (iframes), .ybox-inline-headline (hidden elements), .ybox-share-title (share popup), .ybox-details-title (details panel).קלאסים קיימים — .ybox-img-title (תמונות וגלריות), #ybox-iframe-headline (iframe), .ybox-inline-headline (אלמנטים מוסתרים), .ybox-share-title (פופאפ שיתוף), .ybox-details-title (פאנל פרטים).
  3. CSS variables — --ybox-img-title-color, --ybox-img-title-bg, --ybox-iframe-headline-color, --ybox-share-title-color, --ybox-details-title-color.משתני CSS — --ybox-img-title-color, --ybox-img-title-bg, --ybox-iframe-headline-color, --ybox-share-title-color, --ybox-details-title-color.
  4. Line breaks — write &#10; in the attribute and add white-space: pre-line to the headline class.ירידת שורה — כתבו &#10; בתוך התכונה והוסיפו white-space: pre-line לקלאס של הכותרת.
  5. Rich content (bold words, links, icons) — put the headline inside a hidden element and open it with href="#id", or use data-ybox-details="#id" in galleries.תוכן עשיר (מילים מודגשות, קישורים, אייקונים) — שימו את הכותרת בתוך אלמנט מוסתר ופתחו אותו עם href="#id", או השתמשו ב-data-ybox-details="#id" בגלריות.

Social Sharingשיתוף ברשתות

There are two ways to add sharing buttons to a page: ישנן שתי דרכים להוסיף כפתורי שיתוף לדף:

  1. Via popupפופאפ — a trigger button opens a yBox modal with all the share icons inside.כפתור טריגר פותח מודאל yBox עם כל אייקוני השיתוף.
  2. Inline buttonsכפתורים מוטמעים — share icons placed directly in the page layout, always visible (e.g. on a product card).אייקוני שיתוף מוטמעים ישירות בדף, תמיד גלויים (למשל על כרטיס מוצר).

Option 1: Share popup (.ybox-share)אפשרות 1: פופאפ שיתוף (.ybox-share)

A single trigger button opens a modal with all sharing options.
By default shares the current page URL.
Add href or data-href to share a specific URL instead. כפתור טריגר אחד פותח מודאל עם כל אפשרויות השיתוף.
כברירת מחדל משתף את כתובת הדף הנוכחי.
הוסף href או data-href לשיתוף כתובת ספציפית. 

/* Default — shares the current page URL */
<button type="button" class="ybox ybox-share">Share</button>

/* Share a specific URL with data-href */
<button type="button" class="ybox ybox-share" data-href="https://example.com/product/123">Share</button>

Option 2: Inline share buttonsאפשרות 2: כפתורי שיתוף מוטמעים

Place individual share buttons directly in the page — no popup involved.
Each button needs only the platform class (e.g. ybox-facebook-share-btn).
Add href or data-href on the button itself to share a specific URL, or on the wrapping <ul> to apply the same URL to all buttons inside. מקם כפתורי שיתוף ישירות בדף ללא פופאפ.
לכל כפתור נדרש רק קלאס הפלטפורמה (למשל ybox-facebook-share-btn).
הוסף href או data-href על הכפתור עצמו, או על ה-<ul> העוטף כדי שכל הכפתורים בפנים יירשו אותו. 

/* URL on each button individually */
<button class="ybox-facebook-share-btn" data-href="https://example.com/product/123" type="button">...</button>
<button class="ybox-whatsapp-share-btn" data-href="https://example.com/product/123" type="button">...</button>

/* or set URL once on the wrapping ul — all buttons inherit it */
<ul class="ybox-socials-list" data-href="https://example.com/product/123">
  <li><button class="ybox-facebook-share-btn" type="button">...</button></li>
  <li><button class="ybox-whatsapp-share-btn" type="button">...</button></li>
</ul>

Available platform classes: קלאסי פלטפורמה זמינים: ybox-facebook-share-btn, ybox-whatsapp-share-btn, ybox-twitter-share-btn, ybox-linkedin-share-btn, ybox-pinterest-share-btn, ybox-telegram-share-btn, ybox-copy-text-btn, ybox-print.
